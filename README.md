# 宏大场景故事导演

> 把一句简单设定，扩写成具有宏大世界、完整冲突和连续镜头的视觉故事。

这是一个面向 Codex 的故事与视觉提示词 Skill。用户可以只提供人物、场景、情绪或简单情节，Skill 会补齐故事结构，确定适合的时长，建立角色与场景连续性台账，并生成可直接使用的图片提示词和视频提示词。

默认按照镜头成对交付。每个镜头先输出图片提示词，随后紧跟对应的视频提示词，方便先生成首帧，再制作同一镜头的视频。

## 输出示例

用户输入：

```text
使用 $story-to-visual-prompt-director，创作一个天庭仙女下凡寻找失落星辰的故事，修仙朋克风格，约30秒。
```

Skill 会生成以下结构：

```text
创作假设与交付规格
片名、核心钩子与完整故事
角色卡与世界观视觉圣经
连续性台账
30秒分镜

镜头一
图片提示词
对应视频提示词

镜头二
图片提示词
对应视频提示词

组装顺序、转场建议与连续性检查
```

## 它解决什么

| 常见问题 | Skill 的处理方式 |
| --- | --- |
| 用户只有一句灵感 | 主动补齐目标、阻力、转折、结局与视觉钩子 |
| 不确定故事时长 | 根据事件复杂度选择15秒、30秒、60秒或系列方案 |
| 多张图片人物容易变化 | 建立角色、服装、道具和状态锚点 |
| 多个镜头空间关系混乱 | 记录场景布局、运动方向、光源与镜头结束状态 |
| 宏大场景只有华丽词汇却缺少尺度 | 使用纵深路径、规律递减、空间分层和微小人物参照构建史诗尺度 |
| 图片与视频提示词难以对应 | 按镜头先图后视频成对输出 |
| 视频只有抽象运镜描述 | 写明时长、动作、机位路径、时间线、声音与结尾状态 |

## 适用场景

1. 东方奇幻、仙侠、科幻、修仙朋克与神话短片。
2. 连环海报、故事概念图和多镜头图片组。
3. 文生视频、图生视频与首帧驱动的视频工作流。
4. 15秒至60秒短故事，以及可扩展的系列内容。
5. 换人物、换服装、换场景和局部风格调整。

## 工作方式

Skill 先提取主角、目标、阻力、世界规则和视觉方向，再建立统一的连续性台账。故事按开场钩子、目标、阻力、升级、转折、结局和余韵推进。

每个图片提示词包含人物锚点、场景、动作、构图、光线、材质和负面约束。对应视频提示词继续锁定同一首帧，并补充动作、表情、摄影机路径、声音和镜头结束状态。

生成天庭、仙境、神域、悬空城和巨型遗迹时，Skill 会把“超宽幅史诗场景”作为固定核心视觉锚点，先确定透视消失点和纵深路径，再组织近景、中景、远景与天空层次，通过重复元素递减、微小人物参照、中国建筑结构、克制鎏金、冷暖分离和空气透视强化宏大感。具体建筑与配色会随故事变化，避免机械复制固定场景。用户明确指定竖屏、方形、特写或封闭空间时，会遵循指定构图，并继续通过深景层次与尺度参照维持史诗感。

用户指定 Seedance 2.5、真实感视频或表情表演要求时，Skill 可以调用相应的提示词工作流继续适配。

## 安装

克隆仓库：

```powershell
git clone https://github.com/zhouwei713/story-to-visual-prompt-director.git
```

复制完整 Skill 目录：

```powershell
Copy-Item -Recurse -LiteralPath ".\story-to-visual-prompt-director" -Destination "$env:USERPROFILE\.codex\skills\"
```

安装后，入口文件应位于：

```text
%USERPROFILE%\.codex\skills\story-to-visual-prompt-director\SKILL.md
```

如果本机已经安装旧版本，请先备份并比较文件，再进行替换。开启新任务后即可调用。

## 使用

最短调用：

```text
使用 $story-to-visual-prompt-director，把这个想法写成30秒视觉故事：一名守墓人发现月亮正在坠落。
```

宏大场景调用：

```text
使用 $story-to-visual-prompt-director，创作一个60秒东方神话短片。九座悬空天城在日蚀中逐层熄灭，一名年轻铸剑师必须用最后一柄飞剑重新启动天穹。输出故事、角色设定、连续性台账、分镜，以及每个镜头成对的图片提示词和视频提示词。
```

局部修订：

```text
使用 $story-to-visual-prompt-director，保留现有场景、机位、空间关系和情绪节奏，只把主角换成成年女性机关术师，并同步更新每个镜头的图片与视频提示词。
```

## 设计理念

宏大场景需要清晰的尺度参照、空间层级和故事功能。Skill 会优先让每个镜头推动目标、冲突或情绪变化，同时用连续性台账约束人物、服装、道具、光线和空间方向。
