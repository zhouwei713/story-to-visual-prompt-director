# 中国式宏大场景导演

> 把一句简单设定，扩写成具有宏大世界、完整冲突和连续镜头的视觉故事。

这是一个面向 Codex 的中国式宏大场景故事与视觉提示词 Skill。用户可以只提供人物、场景、情绪或简单情节，Skill 会补齐故事结构，确定适合的时长，建立角色与场景连续性台账，并生成可直接使用的图片提示词和视频提示词。

默认按照镜头成对交付。每个镜头先输出图片提示词，随后紧跟对应的视频提示词，方便先生成首帧，再制作同一镜头的视频。

## 输出示例

用户输入：

```text
使用 $chinese-epic-scene-director，创作一个天庭仙女下凡寻找失落星辰的故事，修仙朋克风格，约30秒。
```

Skill 会生成以下结构：

```text
创作假设与交付规格
片名、核心钩子与完整故事
角色卡与世界观视觉圣经
连续性台账
30秒分镜

镜头一
图片提示词
对应视频提示词

镜头二
图片提示词
对应视频提示词

组装顺序、转场建议与连续性检查
```

## 它解决什么

| 常见问题 | Skill 的处理方式 |
| --- | --- |
| 用户只有一句灵感 | 主动补齐目标、阻力、转折、结局与视觉钩子 |
| 不确定故事时长 | 根据动作可读性选择合适时长，并控制镜头数量 |
| 30秒成片过碎 | 默认压缩到3至4个叙事镜头，每镜头承载完整动作链 |
| 模型单次时长受限 | 使用延长或首尾帧接续，技术分段不增加叙事镜头 |
| 多张图片人物容易变化 | 建立角色、服装、道具和状态锚点 |
| 多个镜头空间关系混乱 | 记录场景布局、运动方向、光源与镜头结束状态 |
| 宏大场景只有华丽词汇却缺少尺度 | 使用五层空间、至少四项可观察尺度证据和微小人物参照构建史诗尺度 |
| 宏大画面被建筑和云雾塞满 | 保留约40%至60%的有内容呼吸空间，让云隙、桥下深空、门洞和远方光线承担空间信息 |
| 大全景容易被写成航拍 | 分别锁定机位高度、观看距离、俯仰角和焦段，按情绪选择低位、人眼高度或城市总览 |
| 图片与视频提示词难以对应 | 按镜头先图后视频成对输出 |
| 视频只有抽象运镜描述 | 写明运镜目的、主运动、速度曲线、运动幅度、人物动作链、声音与结尾状态 |
| 远景人物生成后完全不动 | 为每位人物安排手部动作、视线变化、身体重心变化，以及衣袖、发丝和道具反应 |
| 仙气被大幅运镜破坏 | 使用远景定机、缓慢漂浮、微幅推进、统一风向和单一主要动态，保留建筑稳定与环境缓流 |

## 适用场景

1. 东方奇幻、仙侠、科幻、修仙朋克与神话短片。
2. 连环海报、故事概念图和多镜头图片组。
3. 文生视频、图生视频与首帧驱动的视频工作流。
4. 8秒至70秒短故事，以及可扩展的系列内容。
5. 换人物、换服装、换场景和局部风格调整。

## 工作方式

Skill 先提取主角、目标、阻力、世界规则和视觉方向，再建立统一的连续性台账。故事按开场钩子、目标、阻力、升级、转折、结局和余韵推进。

每个图片提示词包含人物锚点、场景、动作、构图、光线、材质和负面约束。宏大天宫额外执行五层空间、尺度证据和有内容呼吸空间审计。对应视频提示词继续锁定同一首帧，并补充运镜目的、速度曲线、运动幅度、动作能量、声音和镜头结束状态。

生成天庭、仙境、神域、悬空城和巨型遗迹时，Skill 会把“超宽幅史诗场景”作为固定核心视觉锚点，先确定透视消失点和纵深路径，再执行五层空间、四项尺度证据和有内容呼吸空间审计。萝卜哥式风格强调巨景里有生活、华丽里有秩序、仙气来自克制，让小人物的日常动作成为尺度参照与情绪温度。视频优先使用低位或人眼高度的稳定远景、单一主运动、统一风向和柔和环境反应，避免大幅航拍、浓雾和满屏金光。具体建筑与配色会随故事变化，避免机械复制固定场景。用户明确指定竖屏、方形、特写或封闭空间时，会遵循指定构图，并继续通过深景层次与尺度参照维持史诗感。

用户指定 Seedance 2.5、真实感视频或表情表演要求时，Skill 可以调用相应的提示词工作流继续适配。

## 安装

克隆仓库：

```powershell
git clone https://github.com/zhouwei713/chinese-epic-scene-director.git
```

复制完整 Skill 目录：

```powershell
Copy-Item -Recurse -LiteralPath ".\chinese-epic-scene-director" -Destination "$env:USERPROFILE\.codex\skills\"
```

安装后，入口文件应位于：

```text
%USERPROFILE%\.codex\skills\chinese-epic-scene-director\SKILL.md
```

如果本机已经安装旧版本，请先备份并比较文件，再进行替换。开启新任务后即可调用。

## 使用

最短调用：

```text
使用 $chinese-epic-scene-director，把这个想法写成30秒视觉故事：一名守墓人发现月亮正在坠落。
```

宏大场景调用：

```text
使用 $chinese-epic-scene-director，创作一个60秒东方神话短片。九座悬空天城在日蚀中逐层熄灭，一名年轻铸剑师必须用最后一柄飞剑重新启动天穹。输出故事、角色设定、连续性台账、分镜，以及每个镜头成对的图片提示词和视频提示词。
```

局部修订：

```text
使用 $chinese-epic-scene-director，保留现有场景、机位、空间关系和情绪节奏，只把主角换成成年女性机关术师，并同步更新每个镜头的图片与视频提示词。
```

## 设计理念

宏大场景需要清晰的尺度证据、五层空间、内容充足的呼吸感和故事功能。Skill 会优先让每个镜头推动目标、冲突或情绪变化，同时用连续性台账约束人物、服装、道具、光线和空间方向。萝卜哥式表达保留东方建筑的重量，也保留仙女日常的轻，把宏大、生活和仙气放进同一条可生产的视觉链。
